# KAB STAR dashboard

Live dashboard for the KAB STAR low-cost LoRa tide gauge (UiTM final year project).

**Open it:** https://duckpress.github.io/kabstar-dashboard/

`index.html` is the whole dashboard in one file, generated from the project with `tools/build_single_file.py`. It reads live water-level data from the project's Google Apps Script backend.

**Organised version:** https://duckpress.github.io/kabstar-dashboard/organised/

The same dashboard split into small, readable files (`organised/css/` and `organised/js/`, ES modules, no build step). Start with [`organised/README.md`](organised/README.md) for a map of every file.
